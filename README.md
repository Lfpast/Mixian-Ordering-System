# Mixian Order System

This is a simple C++ project used to store, query and manage orders for a fictional "Mixian" shop. It demonstrates several container and data structures implemented from scratch:
- Smart pointer (`SmartPtr<T>`) - simple reference-counted pointer
- Linked list (`LinkedList`) - for maintaining order entries
- Binary search tree (`BST`) - for indexing and range queries
- Hash table (`HashTable`) - for quick lookup by order id

## Build
Requirements: g++ (MinGW or Linux) with C++11 support.

To build on Windows (PowerShell) or Unix environments using GNU toolchain, a Makefile is provided and the project uses `src/` & `include/` structure: 

```powershell
cd path_to_this_directory
make
```

_Note:_ The Makefile automatically adds `-Iinclude` and compiles the sources under `src/`.

## Run
- Run the test suite mode:

```powershell
./system.exe --mode test --testcase 1
```

- Run all tests in a sequence (using helper scripts):

```powershell
make test-all
# or (Windows):
.\scripts\run-tests.ps1
```

- Run the main interactive program (requires a source data text file):

```powershell
./system.exe --mode main --src <source-file.txt>
```

- `external/` (optional) is for vendor/third-party headers such as CLI11; if the vendor header is included in `include/` instead, the `external/` may be omitted.
- `Makefile` automates build targets and has `test-all` which invokes the scripts to run the entire suite.

## Fishbone (Repo) Introduction
The fishbone (Ishikawa) of this repository layout addresses each dimension that affects the project maintenance and publication readiness:

- **Code Organization:** Splitting headers and source files helps keep a clean public API (`include/`) and implementation (`src/`).
- **Build & CI:** A standard build step with `make` and a single spot for adding CI (GitHub Actions).
- **Documentation:** All public functions have Doxygen-style comments; README contains build/run instructions and the file layout.
- **Third-party code:** Vendor/3rd-party (like CLI11) is kept single-file; consider adding in `external/` for even clearer separation.
- **Testing & Demos:** `src/test.cpp` and `GenerateSuite` provide utilities to exercise features and generate sample inputs.

These changes make the project more publishable and better suited for collaboration.
